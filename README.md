# PARKOUR: ROOFTOPS

3D-игра от третьего лица для PICO-8, в которой весь геймплей — паркур.
Ни оружия, ни врагов, ни монеток: только движение, инерция и маршруты.

![cart](parkour.p8.png)

## Запуск

* PICO-8: `load parkour.p8` (или `parkour.p8.png`) → `run`.
* Картридж собирается из исходников: `python3 tools/build.py`.

## Управление

| Кнопка | Действие |
|---|---|
| ⬆️ | бег (держать — разгон) |
| ⬇️ | торможение |
| ⬅️ ➡️ | поворот; на балке — удержание равновесия; на карнизе — перемещение вдоль края |
| 🅾️ (Z) | прыжок; **держать** у стены — wall run / забег на стену; **нажать** на стене — оттолкнуться (tic-tac / wall jump); на карнизе — подтянуться |
| ❎ (X) | подкат на скорости / присед; **перед приземлением** — перекат; на карнизе/лестнице — отпустить |
| ⬇️ + 🅾️ | на карнизе или лестнице — прыжок назад от стены |

Контекстные действия предсказуемы: vault и захват карниза происходят
автоматически только при движении *в* препятствие; стены используются
только пока зажата 🅾️; карабкаться можно только по жёлтым объектам.

## Система движения

| Механика | Как работает |
|---|---|
| Бег | ускорение/торможение/инерция; walk → run → sprint. Максимальная скорость растёт вместе с **flow** (6.2 → 9 м/с) |
| Прыжок | высота и дальность зависят от скорости; прыжок у самого края даёт **edge jump** (+8%); с балки — ниже, с подката/переката — ниже, с навеса — выше |
| Precision jump | прыжок с места/с шага — фиксированный короткий прыжок (~2.2 м) для точных приземлений; приземление на узкое гасит скорость |
| Vault | 3 варианта по скорости: *climb over* (медленно, теряет темп), *vault*, *speed vault* (сохраняет и чуть добавляет скорость). Высокие препятствия нельзя speed-vault'ить |
| Mantle | не долетел до края (до 1.3 м выше ног) — автоматическое забрасывание наверх без остановки |
| Ledge grab / Cat leap | край выше — вис; при быстром подлёте — cat leap (быстрее подтягивание). Подтянуться, отпрыгнуть назад, перемещаться вдоль края, спрыгнуть |
| Wall run | зажать 🅾️ вдоль стены; длительность и подъём зависят от скорости входа, гравитация нарастает — бесконечно бегать нельзя; повторно по той же стене нельзя |
| Wall jump | 🅾️ во время wall run: сохраняет скорость вдоль стены; можно чередовать wall run → wall jump → wall run |
| Wall climb | зажать 🅾️ лицом в стену: забег вверх (~4.4 м с прыжком), затем захват/mantle |
| Tic-tac | нажать 🅾️ при касании стены в воздухе — отталкивание с изменением траектории; каждое следующее без приземления слабее |
| Slide | ❎ на скорости: проскальзывание под трубами, медленно теряет скорость, переходит обратно в бег; прыжок из подката |
| Safety roll | ❎ перед приземлением с высоты: сохраняет скорость, без оглушения (до ~11 м) |
| Hard landing | без переката с высоты: потеря скорости, короткий stun, «тяжёлое» движение, лёгкая реакция камеры. Здоровья нет — ошибка ломает flow |
| Climb | лестницы и трубы (жёлтые): вверх/вниз, прыжок назад, отпустить |
| Balance | узкие балки/трубы/тросы: ⬅️➡️ компенсируют раскачку; на скорости раскачка сильнее; при потере равновесия — срыв (можно поймать край) |

### Flow

Хорошо выполненные движения (vault, wall run, roll, точные приземления,
edge jump…) и долгий бег на скорости наполняют **flow** — он поднимает
максимальную скорость. Ошибки (удар о стену, жёсткое приземление, срыв
с балки, остановка) рвут цепочку и сбрасывают flow. Внизу слева — шкала
скорости, её цвет показывает flow. Очки и цепочка (`vault x6`)
показываются ненавязчиво, на них можно не смотреть.

### Time trial

Таймер идёт с первого нажатия. Лучшее время и сплиты по чекпоинтам
сохраняются (`cartdata`); на чекпоинте показывается разница со
сплитом лучшего забега. После лучшего забега в сессии появляется
**призрак** этого забега. Падение на улицу — мгновенный рестарт с
последнего чекпоинта; в меню паузы — рестарт уровня/чекпоинта.

## Уровень 1 — Rooftops

Каждая крупная секция проходится минимум тремя способами: безопасный
(медленнее), сложный и экспертный (быстрее всего, требует сохранить
momentum).

| Секция | Безопасно | Сложнее | Эксперт |
|---|---|---|---|
| R1 обучение | бег, vault по кондиционерам и стенке, подкат под трубой | | |
| R1 → R2 | прыжок через переулок, перекат | | |
| R2 → R3 (4 м стена) | жёлтая лестница | ящик → будка → два mantle | прыжок + забег на стену |
| R3 → R4 (6 м пропасть) | спуск на низкую крышу S1 и mantle | балансирование по трубе | wall run по билборду |
| R4 → R6 (+3 м / R5 −6 м) | пожарная лестница вниз на R5, подъём по водостоку | отскок от красного навеса → балкон → крыша | с полным flow — прыжок через 6 м и забег на стену R6 |
| R6 → R8 | линия speed vault'ов, подкат, прыжки, балка-мост | | |
| R8 → R9 (бульвар 13 м) | крытый пешеходный мост в обход | трос (баланс 13 м) | wall run → wall jump → wall run между двумя билбордами |
| R9 → башня (5 м) | лестница → площадка → лестница | захват трубы-дымохода, прыжок на крышу | vault на блок → mantle на дымоход → mantle на крышу |

Чекпоинты стоят после крупных секций (7 штук). Финиш — вертолётная
площадка на башне. Автопилот проходит безопасный маршрут за ~49 с,
экспертный — за ~42 с; первый забег живого игрока — пара минут.

## Архитектура

Код разбит на вкладки PICO-8 (`src/*.lua`, порядок в `tools/build.py`):

| Модуль | Ответственность |
|---|---|
| `main` | игровой цикл, режимы (title/play/done), ввод, чекпоинты, таймер, сплиты, HUD |
| `level` | материалы, загрузка геометрии из map-памяти |
| `collide` | ближние боксы, AABB-коллизии по осям, ступеньки |
| `parkour` | детекция (vault, карниз, узкие поверхности), запуск движений, flow/очки |
| `player` | физика и **state machine**: `ground` (бег/присед/баланс), `air`, `vault`, `slide`, `roll`, `land`, `wallrun`, `wallup`, `hang`, `pull`, `climb` |
| `anim` | процедурная анимация: позы-строки, цикл бега, сглаживание поз, скелет и отрисовка персонажа |
| `camera` | камера с запаздыванием, look-ahead, FOV и отдаление от скорости, коллизия штанги |
| `render` | painter's sort: видимые боксы проецируются один раз, затем топологическая сортировка (DFS) по парам с пересекающимися экранными рамками и точным компаратором разделяющих плоскостей; клиппинг по near plane, заливка выпуклых полигонов, туман, окна/рекламы/лестницы, небо, маяк чекпоинта, призрак |
| `fx` | частицы, линии скорости |

Геометрия уровня (130 боксов) хранится в map-памяти и не тратит токены
кода: `tools/level_rooftops.py` описывает уровень функциями `bldg()`,
`ac()`, `tank()`, `box()`, `hint()`. Бюджет: ~8.0k / 8192 токенов,
~12k / 15.6k сжатого кода.

## Инструменты (`tools/`)

* `build.py` — собирает `parkour.p8` (код, уровень, звуки, музыка, лейбл).
* `sim.py` — headless-эмуляция PICO-8 API на Lua 5.4 (lupa): прогон
  кадров, ввод, скриншоты, подсчёт инструкций.
* `playtest.py` — 27 сценариев на каждую механику и каждый маршрут.
* `bot.py` — автопилот проходит уровень целиком (safe/expert), `--gif`.
* `fuzz.py` — случайный ввод: ошибки Lua, NaN, зависшие состояния, застревание в геометрии.
* `make_label.py` — лейбл картриджа.

```
pip install lupa pillow
git clone https://github.com/thisismypassport/shrinko8 /tmp/shrinko8   # шрифт/палитра для скриншотов, подсчёт токенов
python3 tools/build.py && python3 tools/playtest.py && python3 tools/bot.py
python3 /tmp/shrinko8/shrinko8.py parkour.p8 --count
python3 /tmp/shrinko8/shrinko8.py parkour.p8 parkour.p8.png
```

## Ограничения

* Игра тестировалась в эмуляторе (`tools/sim.py`), а не в самом PICO-8:
  синтаксис и бюджет проверены shrinko8, механики — сценариями и ботом.
  Отрисовка ~120–200k инструкций Lua на кадр в эмуляторе (около четверти — эмуляция встроенных функций): физика идёт
  на 60 Гц, кадры рисуются на 30–60 fps.
* Остальные уровни (стройка, промзона, даунтаун, небоскрёб, ночной
  город, мегаструктура) — следующий шаг: движок и формат уровня к ним
  готовы, нужны новые `level_*.py` и материалы.
